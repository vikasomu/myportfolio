# Vikas Narayan Mishra — Portfolio

Premium dark-themed portfolio built with Next.js, React, Framer Motion, and Three.js.

**Live site:** https://vikasomu.github.io/myportfolio/

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI:** React, Tailwind CSS
- **Animations:** Framer Motion, Lenis (smooth scroll)
- **3D Hero:** Three.js via React Three Fiber

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build          # local build
npm run build:pages    # GitHub Pages build (with basePath)
```

### GitHub Pages (alternative)

The site also deploys to the `gh-pages` branch on every push to `main`.

1. Go to https://github.com/vikasomu/myportfolio/settings/pages
2. Source: **Deploy from a branch** → `gh-pages` / `/ (root)`
3. Live at https://vikasomu.github.io/myportfolio/
